# Voyager Explorer

An interactive, story-driven tour of NASA's spacecraft, from the Moon to Voyager 1, built for the NASA Space Apps Challenge "Abandoned but not Forgotten."

## AI assistance

This project was developed with the help of generative AI.

- **Code:** written and revised with Claude, an AI model made by Anthropic. The author reviewed, tested and edited all AI-assisted code and is responsible for how it works.
- **Text:** the captions, notebook entries and interface text were drafted with AI assistance from NASA source material supplied by the author. The author checked the facts against the sources. Where sources disagreed, the text says so or was adjusted.
- **Audio:** All of the spoken lines were generated with AI. We used Speechma for voice generation.
- **Caption reading:** captions are read aloud by the device's built-in speech synthesis. This is not AI-generated content created by the project.

## Sources and credits

- Mission facts: NASA mission pages and NSSDCA catalogue entries, as cited in each caption and notebook entry.
- 3D models and textures: All of them were taken from NASA 3d resources.
- Photographs: NASA/JPL-Caltech and NASA Photojournal, credited under each image.

Some elements are illustrative, not measurements. The Voyager 1 trajectory and the rankings are simulated, as stated in the app.

## Running the project

Install dependencies, then start the development server with `npm install` and `npm run dev`.
